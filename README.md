# Customer Service KPI Dashboard

A modern customer service operations dashboard built with HTML, CSS, JavaScript, and Chart.js.

## Features

- KPI cards with animated counters
- Ticket volume line chart
- Ticket status doughnut chart
- Team leaderboard
- Quality checklist progress bars
- Dark mode toggle
- Responsive mobile layout

## Skills practiced

- HTML semantic layout
- CSS grid and responsive design
- JavaScript DOM manipulation
- Chart.js data visualization
- Dashboard UI design

## How to run

Open `index.html` in your browser.

## How to publish on GitHub Pages

1. Upload all files to a GitHub repository.
2. Go to Settings.
3. Open Pages.
4. Choose the `main` branch.
5. Save.
