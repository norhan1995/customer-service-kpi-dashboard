# CX Command Center — Operations Intelligence

A polished, responsive **customer experience operations dashboard** designed as a portfolio demonstration of contact-center analytics, KPI design, workforce visibility, and service-quality monitoring.

> **Data note:** All figures in this repository are synthetic. No real customer, employee, or company data is included.

## What this project demonstrates

- Executive KPI design for contact-center operations
- Answer rate, service level, ASA, AHT, QA, and CSAT monitoring
- Demand and service-level trend analysis
- Channel-mix visualization
- Quality-assurance dimension tracking
- Team-level performance comparison
- Operational signal / exception surfacing
- Interactive period and team filters
- Dark mode with saved preference
- Responsive layouts for desktop, tablet, and mobile

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js 4
- Google Fonts

No build step or framework is required.

## Run locally

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/norhan1995/customer-service-kpi-dashboard.git
cd customer-service-kpi-dashboard
```

Then open `index.html`.

## Portfolio positioning

This is a front-end analytics demonstration, not a production contact-center platform. It focuses on communicating operational insight clearly and presenting KPI logic in an executive-friendly interface.

## Next production steps

A production version would connect to a secured analytics API or warehouse, add authentication and role-based access, define source-of-truth KPI calculations, add date-range querying, and include automated tests and accessibility validation.
